### P0-1 小程序 AppSecret 明文存储，且存在两套不一致的凭据

**风险等级：安全 · 极高** · **状态：代码侧已处理，待后台重置密钥**

两处明文密钥，且互相矛盾：

| 位置 | AppID | AppSecret |
|---|---|---|
| `新建 文本文档.txt`（项目根目录） | `wx5a7366b5deaa5ac8` | `21fcc...`（明文） |
| `yqsss-uniapp/uniCloud-alipay/cloudfunctions/yqsss-auth/.env` | `wxa1...` | `75ed...` |

项目实际 AppID（`project.config.json` / `src/manifest.json`）为 `wx5a7366b5deaa5ac8`，与云函数 `.env` 中的 `wxa1...` **不一致**。

后果：云函数用错误 AppID 去微信服务器换 openid，必然返回 `40029 invalid code`，**微信一键登录 100% 失败**。

处置步骤：
1. 删除根目录 `新建 文本文档.txt`（或移出项目目录并加入 `.gitignore`）。
2. 登录微信公众平台 → 开发管理 → 开发设置 → **重置 AppSecret**（无法确认是否已外泄，重置是唯一安全做法）。
3. 将云函数 `.env` 的 `WX_APPID` 改为 `wx5a7366b5deaa5ac8`，`WX_APPSECRET` 填重置后的新值。
4. 在 uniCloud 控制台「云函数配置 → 环境变量」同步配置同名变量（云端不会读取本地 `.env`）。
5. 确认 `.gitignore` 已排除 `.env`（当前 `yqsss-uniapp/.gitignore` 已正确排除，保持即可）。

> 注：云函数 `.env` 已在 `.gitignore` 中排除，这点做得对；问题出在根目录那个未被排除的 txt。

### P0-3 隐私保护指引缺失，海报保存功能将被拦截

**风险等级：合规 + 功能失效 · 高** · **状态：代码侧已处理，待后台提交指引**

> **已执行**：
> 1. `src/manifest.json` 的 `mp-weixin` 节点加入 `"__usePrivacyCheck__": true`，已验证编译进 `app.json` 生效。
> 2. `poster.vue` 的 `save()` 拆为 `saveWithPrivacyCheck()` → `doSave()` 两级：
>    - 微信端先调 `uni.requirePrivacyAuthorize`，未同意则弹窗并可跳转隐私协议（`uni.openPrivacyContract`）；
>    - 低版本基础库无该 API 时自动降级直接保存；
>    - 保存失败若因相册权限被拒，引导 `uni.openSetting` 重新授权（原实现只提示长按）。
> 3. 用条件编译隔离，H5 端行为不变。
>
> **仍需你在后台完成**：提交《用户隐私保护指引》并勾选「相册（仅写入）」。未提交前，隐私接口仍会被拦截。

`pages/poster/poster.vue` 调用了 `uni.saveImageToPhotosAlbum`（写入相册）。该接口在微信**属于隐私接口**（对应「相册」权限）。

当前状态：
- `src/manifest.json` 的 `mp-weixin` 节点**未配置** `__usePrivacyCheck__`。
- 代码中未接入 `wx.requirePrivacyAuthorize` / `uni.requirePrivacyAuthorize`。
- 未查阅到任何隐私保护指引配置。

2026 年平台规则：用户未同意隐私保护指引前，**所有隐私接口调用会被静默拦截**。表现是用户点「保存海报」直接失败，而代码里的 `fail` 回调只会提示「当前环境不支持直接保存」——用户会认为是 Bug。

处置步骤：
1. 微信公众平台 → 设置 → 服务内容声明 → **用户隐私保护指引**，提交并公示（需勾选「相册（仅写入）」）。
2. `src/manifest.json` 的 `mp-weixin` 节点加入：
   ```json
   "mp-weixin": {
     "appid": "wx5a7366b5deaa5ac8",
     "setting": { "urlCheck": false },
     "usingComponents": true,
     "requiredPrivateInfos": [],
     "__usePrivacyCheck__": true
   }
   ```
3. `poster.vue` 的 `save()` 方法在调用保存前，先请求隐私授权：
   ```js
   // 仅在微信端需要
   // #ifdef MP-WEIXIN
   uni.requirePrivacyAuthorize({
     success: () => this.doSave(),
     fail: () => uni.showToast({ title: '需要同意隐私协议才能保存', icon: 'none' }),
   });
   // #endif
   ```
4. 保存失败时增加「去设置开启相册权限」引导（`uni.openSetting`），当前只提示长按，体验偏弱。
