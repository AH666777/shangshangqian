# 项目文档索引

本目录集中存放「一键上上签」的全部项目文档。代码仓库根目录只保留 `README.md`（项目总览）与工程配置，其余文档一律归档到这里。

## 目录约定

| 目录 | 放什么 | 典型文档 |
| --- | --- | --- |
| [`planning/`](planning/) | 立项需求、产品方案、功能规划、商业化策略。**写「要做什么」** | 命名方案与落地计划、成就系统方案、多平台发布计划 |
| [`reports/`](reports/) | 评审结论、审计报告、上线前核查。**写「做得怎么样」** | 代码与测试审计报告、发布前检查清单 |
| [`operations/`](operations/) | 部署步骤、环境变量、故障排查记录。**写「怎么跑起来」** | 云函数部署与登录验证记录 |

新增文档时按上表归位；一份文档只放一处，不建副本。跨目录引用统一用相对路径（如 `../reports/xxx.md`）。
