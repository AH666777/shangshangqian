# 🏮 一键上上签

> 摇一摇签筒，抽一支属于你的上上签。

一款国风趣味的抽签小游戏。选一个当下的场景，摇动签筒，抽一支签，看看今天有什么话想对你说。

**提供网页版与微信小程序版两种形态：网页版打开即玩，小程序版支持微信登录与云端同步。**

---

## 这是什么

「一键上上签」把庙里摇签筒的仪式感，做成了一款随手可玩的小应用。

不需要注册、不需要下载，打开就能抽。抽到的签会配上一段签诗和五句生活提示，可以存进历史慢慢回看，也可以生成一张国风海报分享出去。

**它是一款娱乐小游戏，不是命理预测工具。** 签文由算法随机生成，图的是个好彩头，不是给你的人生下判断。

## 主要功能

### 🎋 四种抽签场景

每次抽签前先选一个场景，签文会围绕这个场景来写，读起来更贴你当下的事。

| 场景 | 适合 | 一句口彩 |
| --- | --- | --- |
| ☀️ 日常好运 | 平平常常的每一天 | 每日好运 |
| 📚 考试通关 | 备考、考试、查分 | 逢考必过 |
| 💼 开工大吉 | 上班、接活、开张 | 事业顺利 |
| 🎉 节日祈福 | 过节、生日、纪念日 | 万事如意 |

### 🪄 摇签抽签

- 摇一摇手机，或者点一下签筒，签就出来了。
- **每天有 3 次免费机会**，用完后可以看完一段广告继续抽，也可以解锁「无限抽签」随便抽。
- 每次结果都当场随机生成，不会因为你抽得多了就变差。

### 📜 签文与等级

签分四档，从高到低：

| 等级 | 含义 |
| --- | --- |
| **上上签** | 顶好的签，诸事顺遂 |
| **上吉签** | 顺遂偏吉，值得高兴 |
| **中平签** | 平稳无波，按部就班就好 |
| **蓄力签** | 不是坏签。意思是此刻宜蓄力，不必急着往前冲 |

此外还有 6 种**特色签**：锦鲤签、万能上上签、定制好运签、龙腾签、福寿签、天赐签。它们平时不在签池里，解锁「高级签」之后才有机会抽到，抽中就是意外之喜。

> 关于「蓄力签」：我们把传统签筒里最容易让人心里一沉的那一档，换成了中性的说法。它想表达的是「现在适合积累」，而不是「你运气不好」。

### 🔍 解签

每支签都会给你这些内容：

- **签诗**：四句国风短诗，是这支签的题眼。
- **白话解读**：把签诗翻成今天能听懂的话。
- **五维提示**：从事业、学业、财运、健康、情感五个方向，各给一句轻量的生活提醒。

想看更详细的解读，可以解锁「深度解签」。

### 🖼️ 分享海报

抽到喜欢的签，可以一键生成国风海报，保存到相册或直接分享给朋友。海报上带签文、等级和日期，适合发朋友圈。

### 📖 历史记录

每次抽签都会自动存下来，按时间倒序排好，能看到当时抽的是什么签、什么等级、什么时候抽的。不想留了可以一键清空。

### 🏅 成就系统

内置 **49 个成就**，分成 7 个系列：

| 系列 | 主题 |
| --- | --- |
| 积累之路 | 抽得越多，走得越远 |
| 签运时刻 | 记录每一次好签 |
| 场景探索 | 在不同场景留下足迹 |
| 时段彩蛋 | 特定时刻的惊喜 |
| 权益玩法 | 解锁更多玩法 |
| 进阶挑战 | 坚持与分享 |
| 彩蛋奇遇 | 一些没什么用但很好玩的记录 |

成就解锁时会弹出提醒，在小程序版里还会同步到云端，换设备也不会丢。

### ☁️ 登录与数据同步（小程序版）

微信一键登录，抽签记录、成就、统计都会存到云端。换手机、重装小程序，数据都还在。

网页版不登录也能玩，数据存在浏览器本地。

## 使用说明

### 网页版

1. 打开链接，进入首页。
2. 在「选择你的场景」里点一个场景（默认是日常好运）。
3. 点击签筒，或摇动手机。
4. 签出来后点「查看解签」，看签诗和五维提示。
5. 想留存就点「生成海报」，想回看就进「历史记录」。

> 网页版无需安装、无需登录。清除浏览器数据会一并清掉本地记录。

### 微信小程序版

1. 打开微信，通过小程序码或好友分享的卡片进入「一键上上签」。
2. 首次进入点「微信登录」，授权后即可抽签。
3. 后续操作与网页版一致，数据自动同步到云端。

> 小程序版正在上线准备中，正式发布后可直接在微信内搜索「一键上上签」进入。

### 关于每日次数

每天 3 次免费机会，**次日零点重置**。用完后有三种选择：

- 看完一段广告，继续抽；
- 解锁「无限抽签」，当天不再受限；
- 明天再来。

## 常见问题

**签文准不准？**
它不准，也不需要准。签文是算法随机生成的国风文案，作用是给你一个停下来想一想的瞬间。请把它当成一句玩笑话式的鼓励，而不是预测。

**抽到「蓄力签」是不是运气不好？**
不是。这一档想说的是「现在适合积累，不必急着冲刺」。四档签都有各自的解读，没有哪一档是「坏签」。

**每天能抽几次？**
3 次免费。看完广告可以继续，也可以解锁无限抽签。

**换手机会丢记录吗？**
小程序版登录后数据存在云端，不会丢。网页版存在浏览器本地，清缓存会丢。

**可以不登录吗？**
网页版可以，直接用昵称就能玩。小程序版的云端同步需要微信登录。

**为什么同一支签会重复出现？**
签文库是固定的，抽得多了自然会遇到重复。但每次抽签的结果都是独立随机生成的。
